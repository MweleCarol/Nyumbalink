# NyumbaLink

A mobile-first rental discovery and house-viewing platform for the Kenyan market.

House seekers search rental houses and request physical viewings. Landlords, caretakers, and agents manage the properties they are authorized to manage. Administrators verify providers and moderate listings.

## Status

Phase 1: project foundation (in progress). Nothing beyond the repository skeleton is implemented yet.

## Structure

- `backend/` - Node.js, Express, TypeScript, Prisma, PostgreSQL API
- `apps/mobile/` - React Native, Expo, TypeScript mobile app
- `docs/` - design documents (HLD, LLD) and development guides
